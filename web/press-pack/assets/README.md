# `press-pack/assets/`

What the press pack needs that this repository cannot generate. One file today, named by
`press-pack/manifest.yaml` and copied into the archive by `npm run press:pack`:

- **the one-page technical rider**, e.g. `rider-2026-09.pdf`.

It is tracked in git, unlike the photographs and unlike the built archive: a one-page PDF is small,
it is the ensemble's own statement about how it performs, and losing it would mean asking for it
again.

**Nothing in it may be estimated.** The `/press` that shipped until 2026-07 printed a rider whose
every number was invented — reverb ≥ 2 s, a 6 × 4 m platform, 12–14 voices, 60–75 minutes — and all
of it was deleted rather than corrected. The rider returns when the ensemble writes one.

`docs/specs/web-press-pack-2026-09.md` §3 carries the request to send them, including what the page has
to be able to say once it arrives.
